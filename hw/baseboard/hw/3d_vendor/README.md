# Vendor 3D models

These models are referenced by the PCB, but they are not distributed with this repository because their vendor licenses do not allow redistribution. Download them from the manufacturer and save them here under the listed file names to get a complete 3D view. The design, fabrication and assembly outputs do not depend on them.

| Board ref. | Part | Expected file name | Source |
|---|---|---|---|
| J4 (K26 SOM on J3/J4) | AMD Kria K26 SOM (SM-K26-XCL2GI) | `SM-K26-XCL2GI.STEP` | AMD Kria K26 SOM product page |
| J5 | TE Connectivity SFP+ cage 2227023-1 | `TE_2227023-1.stp` | TE Connectivity product page for 2227023-1 |

Everything in this folder except this README is ignored by git.
