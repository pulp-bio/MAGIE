# PCB Layout review checklist
Copied and modified with permission from Mark Harris, original link: <https://resources.altium.com/p/pcb-design-and-review-checklist>
## Before Submitting Your Board for PCB Design Review
- [x] Check for unrouted nets
- [x] Repour all polygons
- [x] Ensure your board has a complete silkscreen, including:
    - [x] ETH logo(s)
    - [x] Project logo(s)
    - [x] Copyright notice
    - [x] Warning/Hazard label(s) and Icons
    - [x] Connectors are labeled, and pinouts are called out where relevant
    - [x] QA/Test block with QR code, blank areas for board number, dates, and QA/Test checkmarks
    - [x] Board name, print date, and revision number
    - [x] If there are designators on the silkscreen, then check:
        - [x] Each designator is close to and clearly identifies the associated component
        - [x] All designators are only in one or two orientations
        - [x] Text size and font will remain legible after the fabrications process
    - [x] ICs have pin one clearly marked, i.e., the pin one marker is not located under another component
- [x] Update the PCB from its schematics to ensure the schematic and board are synchronized
- [x] Ensure the design rule report passes with no errors
    - [x] Ensure there is a design rule to catch nets with only 1 pin
- [x] Ensure you have the board outline on a mechanical layer that will go to the board fabricator
- [x] Fiducials (copper reference markers) are present for the assembly and meet these criteria: TODO!
    - [x] Three board-level fiducials are included as a minimum
    - [x] Two fiducials are diagonally opposing each other across all extremely fine-pitch components
- [x] Mounting points have sufficient clearance for the chosen washer and screw head
- [x] If an enclosure model is available, it has been tested against the board to ensure there will be no interference between the enclosure and components
    - [x] All components (including mechanical items) have accurate 3D models
- [x] Your board is fully production-ready, as far as you are concerned, before sending it to colleagues for a design review checklist.

## Layers
- [x] Check the layer stack and substrate heights meet the fabricator's specifications (or that the fabricator can meet your specifications)
- [x] Check the copper thickness on all layers matches the target fabricator's specifications (or that there is a callout on the documentation layer for the required copper thickness)
- [x] Ensure there is at least one continuous, unbroken ground plane
- [x] If your board has controlled impedance nets, they are correctly set up both on the layer stack and in the design rules
- [x] Check if any keep-out track matches the board shape
    - [x] Check any board cutouts or slots used for a keep-out barrier to prevent nets from crossing milled areas
## Signal Path
- [x] Ensure that the ground plane has sufficient current-carrying vias near connectors, and voltage/return sinks
- [x] If required/relevant, ensure voltage planes and areas have sufficient connection vias for current requirements
- [x] Ensure tracks to reference planes are sufficiently wide for current requirements
- [x] Check there are sufficient quantities of vias for the current-carrying capacity of traces
- [x] Check the minimum track widths for all current-carrying nets are sufficient. Consider if a design rule is required
- [x] Check all ground pins have a via to the ground plane
- [x] Check there is a continuous ground plane within one signal layer of any signal trace
- [x] Check any controlled impedance traces have the correct net rules and impedance profile
- [x] Check differential pair tracks are as close together as possible
- [x] Check differential pair tracks lengths are matched
- [x] Check all high-speed signals are length matched, specifically including:
    - [ ] DDR
    - [ ] PCIe
    - [ ] Ethernet
    - [x] LVDS
    - [ ] HDMI
    - [ ] USB3+
    - [ ] MIPI
    - [ ] JESD204
- [x] Check every signal trace has a constant impedance along its length. If the trace changes layer, its impedance should stay the same
- [x] Check traces longer than 1/6th of the rise or fall time of the signal have been simulated:
    - [x] Check termination resistors, or another termination is present to prevent ringing or overshoots
- [x] Check termination resistors are in the relevant locations
- [x] Check long traces that hug other traces that have been simulated for crosstalk
- [x] Check all high-speed traces run over a continuous ground pour
- [x] Ensure that no sensitive nets run under noisy components
- [x] Check that the vias for decoupling capacitors are not shared TODO: check
    - [x] Each decoupling capacitor requires its own via for VCC and for GND direct to reference planes
## Components
- [x] Check all through-hole pads are set to plated if they are going to be soldered
- [x] Check there is sufficient clearance for the following:
    - [x] For pick and place heads in production
    - [x] For hand assembly in prototypes
    - [x] For soldering pen tip access if any rework is required
- [x] Check bypass capacitors are placed as close to IC power pins as possible (under 15mm)
- [x] Check crystal/oscillator clock sources are as close to the IC clock pins as possible Maybe put Y3 & Y4 under FPGA?
- [x] Check termination resistors are as close to the signal source as possible
- [x] Check EMI/RFI filtering is as close to the exit point (board edge, connector, shield) as possible
- [x] Check potentiometers increase signal/voltage when turned clockwise TODO!
- [x] Check programmable devices have accessible programming header/pads
- [x] Check no high thermal mass components (e.g., large transformers/inductors) are located next to very small components
- [x] Check component placement prioritizes short track lengths for high-speed signals
- [x] Check there are a sufficiently large copper area for heat-sinking high-dissipation devices, including:
    - [x] Linear regulators
    - [x] Switched-mode power supplies (including LED drivers)
    - [x] High power LEDs
    - [x] High-frequency gate drivers
    - [x] MOSFETs
    - [x] Motor drivers
    - [x] Chargers
    - [x] High-speed microprocessors
    - [x] Power amplifiers
## Testing
- [x] Check that test pads are sufficiently far from the edge of the board to allow fixturing
- [x] Check test pads do not create stubs/impedance mismatch on high-speed nets
- [x] Check that component do not obstruct access to test pads for manual testing (e.g., using an oscilloscope probe)
- [x] Check test pads are clearly labeled for prototypes
- [x] Check any signal needed for testing or inspection has a test point
- [x] Check test points are all located on the same side of the board, ideally:
    - [x] The bottom of the board for access using a bed of nails fixtures
    - [x] The top of the board for manual access with test equipment (e.g., oscilloscope probes)
## Protection/EMI/EMC
- [x] Check appropriate creepage and clearance rules are set for all high-voltage nets
- [x] Check if separate earth tracks/paths are necessary for ESD
- [x] Check there are decoupling capacitors next to connectors and vias that may require them
- [x] Check TVS diodes or other ESD mitigation component pads are in series with the track to the component (i.e., any ESD event must pass through the component pad before getting to a sensitive device)
- [x] Ensure there are no track stubs/net antennas going to test points or unused connector pins
- [x] Ensure high-speed signals are routed as directly as possible—no scenic routes
- [x] Check any track carrying over 100mA has its width calculated to ensure it is of sufficient size for the current
    - [x] If the board will be fitted within an enclosure with little or no airflow, calculate or simulate the width for an internal layer instead of an external layer
- [x] Check if an RF shield is required anywhere on the board and if it has a sufficient footprint
- [x] If you are using a two-layer board: no
    - [x] Are there any ground loops?
    - [x] Is there a ground track of sufficient size for the return current of every device?
    - [x] Is there an unbroken ground pour under every high-speed trace?
- [x] If you have multiple grounds, ensure that they are tied together at a single point only
## Panels
- [x] Ensure that there is sufficient frame area for conveyors and clamping
- [x] Ensure that the silkscreen includes the following:
    - [x] Blanks for QA/Testing marks
    - [x] Print date
    - [x] Machine name
    - [x] Company name
    - [x] Panel barcode
    - [x] Board part number and revision
- [x] Check panel fiducials are present
- [x] Check for an origin identification mark
- [x] Check impedance/layer/other test areas are present if required
- [x] Check V Score/Milling/tab layers are present and aligned with the board if they are not in the board file
- [x] Check the panel isn't too large for the board thickness and any milling (i.e., low flexibility/bounce)
